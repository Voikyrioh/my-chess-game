# chess — Guide pour Claude

## Lire en premier

1. **ARCHITECTURE.md** — carte du code (engine, renderers).
2. **docs/INDEX.md** — point d'entrée docs.

## Rôle du repo

Jeu d'échecs standalone. TypeScript engine pur + renderers HTML/3D (Three.js).

## Commandes

- Dev : `npm run dev` → http://localhost:5173
- Tests : `npm run test`
- Build : `npm run build`
- Lint : `npm run ci`

## Skills obligatoires

- `/code-search` — localiser règles/renderer.
- `/dev-task` — implémentation.
- `/business-rule` — nouvelles règles.
- `/doc-update` — maintenir docs.
